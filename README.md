# 🌿✨ WellnessBuddy – Android App (Kotlin)

![Welcome Banner](https://capsule-render.vercel.app/api?type=waving\&color=0:43cea2,100:185a9d\&height=200\&section=header\&text=WellnessBuddy\&fontSize=40\&fontColor=ffffff\&animation=fadeIn)

## 📱 Overview

![App Preview Animation](https://media.giphy.com/media/coxQHKASG60HrHtvkt/giphy.gif)

🌱 **WellnessBuddy** is a modern Android application built using **Kotlin** that helps users build, track, and maintain healthy daily habits with ease and consistency.

💡 It focuses on simplicity, motivation, and productivity through smart reminders and clean UI/UX design.

---

## ✨ Key Features

* 📌 Habit tracking system for daily wellness goals
* ⏰ Smart reminder notifications to stay consistent
* 💾 Offline local data storage support
* 🎯 Clean, modern & intuitive UI/UX design
* ⚡ Optimized performance for smooth experience
* 📊 Progress tracking for motivation boost
